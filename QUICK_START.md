# 🚀 ARATTAI - Quick Start Guide

## ⚡ Get Started in 2 Minutes

### **Step 1: Start Frontend** (Already Running)
```bash
npm run dev
```
✅ Frontend running at `http://localhost:3000`

---

### **Step 2: Start Backend** (Optional but Recommended)
```bash
# Open a new terminal
cd backend

# Install dependencies (first time only)
pip install -r requirements_agents.txt

# Start the server
python main_agents.py
```
✅ Backend running at `http://localhost:8000`

---

## 🔍 **Troubleshooting**

### **Backend Not Connecting?**
1. Check if backend is running: `http://localhost:8000`
2. Visit API docs: `http://localhost:8000/docs`
3. Check terminal for errors

### **Voice Input Not Working?**
- Make sure you're using Chrome/Edge (best support)
- Allow microphone permissions
- Check browser console for errors

### **3D Particles Not Showing?**
- Refresh the page
- Check browser console
- Make sure you're on the landing page (`/`)
